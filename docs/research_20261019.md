approximations are explicitly named lite; the previous synthetic GPU smoke
report does not establish that official pretrained models ran successfully.

The PDFs were treated as scientific source material, not instructions. They
are not redistributed. All weights remain subject to their original licenses.

## Pinned sources and exact weight loading

- GenFocal: `0beb5d20a5b31969e12069ba7d86fc0537e08528`, Apache-2.0 code,
  CC-BY-4.0 released weights. Both stages use checkpoint step 300000.
  Debiasing loads raw `params`; SR loads `ema_state.ema`, matching upstream
  inference. Range reads exclude optimizer state. The original Orbax metadata
  restores literal dots in module names, with SHA-256 checks for cached tensors.
- GraphCast: `08cf73625c9d12bd9aaa038868bcb2fe488f2a22`, before the upstream
  WeatherNext package reorganization. Apache-2.0 code, CC-BY-NC-SA-4.0 weights.
  Default is operational 0.25°/13 levels; 37-level and official 1° small variants
  are selectable. All include the original normalization statistics.
- PBC: `d59e18f720bac712e18563bd469d4679c120f9e5`, MIT. Original scripts run in
  a separate working data directory. Coefficients require historical forecast,
  reforecast and observation data; there is no substitute random checkpoint.

The released GenFocal debiasing channels are **768/768/768/1024/1280/1536**.
The earlier 128-channel description was an example configuration, not the
published model. CONUS SR has **148,738,720 parameters / 594,954,880 bytes**
of EMA tensors; the full archive also includes training state/other checkpoints.

```python
from weatherai import GenFocal, PBC, Translocation
sr = GenFocal.from_pretrained('super_resolution')
flow = GenFocal.from_pretrained('debiasing')
pbc = PBC(work_dir='pbc-work')
diagnostic = Translocation.from_pretrained('operational')
```

Use the dedicated Linux/Python 3.12 JAX environment in `hf_official/requirements.txt`
for neural models. PBC's complete author pipeline recommends Python 3.13.
Set `WEATHERAI_CACHE` to a large local directory; do not commit weights.

## Actual validation

- Local official PBC execution: original climatology, projection and equal-weight
  ensemble scripts pass a transparent NetCDF fixture. [Report](results/pbc_official_execution.json).
  This verifies execution/numerics, not historical fitting or the paper's scores.
- Main/lite separation, Orbax tree reconstruction and checksum corruption tests,
  plus existing lite numerical tests: 17 passed.
- WeatherPre: 60 passed, 6 skipped. Default research loading is official and
  there is no fallback after a pretrained loading error.
- Official GraphCast **0.25-degree operational / 13 levels**: **PASS**, real
  ERA5 2022-01-01 input, one 6h forecast, all 11 output variables finite, 36.12 s.
  [Full-resolution report](results/graphcast_official_zerogpu.json).
  Official pretrained 1-degree Small also passed (10.86 s).
- Official GenFocal ReFlow: **PASS**, all 2,656,553,626 published parameters
  (10,626,214,504 bytes), full `(1,8,240,121,10)` output, 146.13 s.
  Inputs are synthetic normalized fields; this is a vector-field evaluation,
  not complete physical debiasing. [Report](results/genfocal_debias_official_zerogpu.json).
- Official GenFocal CONUS SR/EMA: **PASS**, real ERA5 2015-08-01..07 conditions,
  full `(1,84,120,240,4)` denoiser output, 52.99 s. This evaluates sigma=1 with
  a zero residual, not the complete diffusion sampler. [Report](results/genfocal_sr_official_zerogpu.json).
- Actual `Translocation` official API / signed ERF: **PASS**, pretrained Small
  model, ERA5 2022 data, 18 finite input-gradient fields, nonzero sensitivity,
  20.45 s. [Report](results/graphcast_small_erf_official_zerogpu.json).
- Official GPU results are recorded per stage under `docs/results/*_official_zerogpu.json`.
  Read the `status`, `scope`, original source revision, checkpoint and input-data
  fields; an ERROR report is a failed attempt, not an inference success.
  `research_20261019_zerogpu.json` is the earlier **lite-only** synthetic report.

Run `python scripts/run_official_hf.py graphcast` (or `graphcast_small`,
`genfocal_sr`, `genfocal_debias`) against the
[dedicated official ZeroGPU Space](https://huggingface.co/spaces/LonghaoWang/weatherai-official).
Preparation runs on CPU; pretrained compute uses the ZeroGPU allocation.

A single GenFocal denoiser/vector-field evaluation is not complete climate
sampling. GraphCast's real ERA5 sample is not the Dubai 2024 reconstruction.
PBC fixtures do not reproduce RPSS. No full paper skill or production readiness
is claimed. Detailed stage limitations appear on the three model pages.

## WeatherPre integration

[WeatherPre](https://github.com/GISWLH/WeatherPre) registers calibration,
downscaling and diagnostic roles with `research` status. `load_research` defaults
to official code/weights; experimental PyTorch models require `lite=True`.
Research outputs do not enter automatic deterministic forecast rankings.
Existing Aurora endpoints are preserved. HF storage was sufficient; no existing
Space or user data needed deletion.
