## Verification and limits

Actual ZeroGPU result: **PASS**, NVIDIA RTX PRO 6000 Blackwell Server Edition
MIG 2g.48gb, PyTorch 2.13.0+cu130. First run took 2.09 s and allocated a peak
66.86 MiB. PBC CPU/CUDA max absolute difference: 7.45e-7. GenFocal two-stage
backward and sampling, and GraphCast signed ERF were finite. The timestamped
JSON below is authoritative for the latest deployed revision.

Run `python -m pytest tests/models/pbc tests/models/translocation tests/models/genfocal -q`.
The new tests use analytical/NumPy/SciPy references; existing GenFocal tests
also check the previously stored official JAX flow references. Run
`PYTHONPATH=. python scripts/research_smoke.py --device cpu` locally and
`python scripts/run_research_hf.py` against the deployed ZeroGPU endpoint.
Remote evidence is saved under `docs/results/research_20261019_zerogpu.json`
only after an actual CUDA result, with the Space revision and GPU name.

No official weights were loaded into the new native models. No ERA5 forecast
skill score, full paper replication or production readiness is asserted.
PBC is a fit-to-data statistical algorithm; GenFocal lite is not Orbax weight
compatible; Translocation is an analysis wrapper around an existing model.
