# Candidate weather / climate AI models in Nature- and Science-family journals

*Research note — generated 2026-10-02 (HKT); refined 2026-10-02 after the user selected nine models (see “Selected for implementation”).*

**Scope.** ML weather/climate models published in Nature, Science and their families only
(Nature, Science, Nature Communications, Nature Geoscience, Nature Climate Change, Nature Machine Intelligence,
Nature Computational Science, Communications Earth & Environment, npj Climate and Atmospheric Science, Science Advances, Science Robotics).
Already in the repo and therefore excluded: Pangu-Weather, FuXi, FengWu, GraphCast, GenCast, NeuralGCM (2024 paper), Aurora, Aardvark, NowcastNet, FuXi-ENS, FuXi-DA, WeatherNext Cyclones.

**How it was built (so you can judge the confidence).**
1. ~35 topic queries × 10 journals against the **Crossref API** (ISSN-filtered, 2019–2026) → several hundred distinct titles, manually filtered for ML weather/climate models; plus targeted web searches.
2. Every DOI below was re-fetched from Crossref (`/works/<doi>`) and the title / journal / volume / article number / year are copied from that record.
3. Code/weights availability comes from the paper's own *Code/Data availability* section (nature.com pages; Europe PMC full text for Science Advances) and was then probed on GitHub (README via raw URLs), Zenodo and Hugging Face APIs. “Not checked” means exactly that. GitHub's REST API was rate-limited from the box, so repository licences/star counts were not collected.
4. This is a **best-effort, not exhaustive** list: Crossref relevance search can miss papers, and unreleased/in-press items are invisible.

**Feasibility scale** (for a *lite* native-PyTorch version in this repo, following the Pangu/FuXi/Aurora/GenCast pattern: explicit modules, strict weight load, numerical check vs the official implementation):
**Easy** = open PyTorch code (+ ideally weights), small/medium model; **Medium** = open code or weights but conversion/data/size effort; **Hard** = weights only as ONNX/SavedModel or very large; **Blocked** = no public code/weights; **Unverified** = availability could not be confirmed.

**Corrections to the names in the request** (verified): FuXi-S2S is *Nature Communications* **2024** (not 2025); FuXi-Weather is *Nature Communications* 2025; CorrDiff is *Communications Earth & Environment* 2025; the ACE paper in the family is **ACE2** (*npj Clim. Atmos. Sci.* 2025); NeuralGCM-precipitation is *Science Advances* 2026; ArchesWeatherGen is *Science Advances* 2026. Several asked-for models are **not** in these families — see §Excluded.

## Recommended implementation priority (top 8, original ranking)

Criteria: open code **and** public weights, PyTorch (or small JAX delta to what the repo already has), a verifiable official reference, and complementing what is already in the repo (medium-range, ensembles, cyclones, S2S/climate are covered or partly covered; **climate emulation, downscaling/km-scale, ocean/seasonal and S2S are not**).

1. **ArchesWeatherGen / ArchesWeather** (*Sci. Adv.* 2026) — PyTorch, BSD, HF weights (0.34 GB deterministic / 1.9 GB generative), full training pipeline; architecturally close to the existing Pangu/Aurora blocks. Lowest risk, high value (probabilistic medium-range with public weights).
2. **ACE2** (*npj Clim. Atmos. Sci.* 2025; also gives the Kent et al. seasonal forecasts) — PyTorch, Apache-2.0, HF checkpoint, 450 M parameters. Adds the missing *climate-emulator* category; reuse the verified torch SH layer.
3. **CorrDiff** (*Commun. Earth Environ.* 2025) — PyTorch/PhysicsNeMo (Apache-2.0); adds *downscaling*; shares EDM machinery with the GenCast port. Confirm checkpoint/data access first (HF repo returned 401; Taiwan dataset is CC BY-NC-ND).
4. **StormCast** (*Sci. Adv.* 2026) — PyTorch/PhysicsNeMo, Apache-2.0, HF weights (≈0.8 GB); km-scale regional diffusion; natural companion to #3 (same EDM-UNet family).
5. **NeuralGCM precipitation checkpoints** (*Sci. Adv.* 2026) — Zenodo CC-BY-4.0 45 MB checkpoints; smallest delta because the repo already has the NeuralGCM native towers, SH layer and a JAX train/fine-tune workflow.
6. **ORCA-DL** (*Sci. Adv.* 2025) — PyTorch, public weights (HF dataset repo), seasonal–decadal 3-D ocean; adds *ocean/seasonal/ENSO*; same group as FengWu.
7. **FuXi-S2S** (*Nat. Commun.* 2024) — ONNX weights (2.08 GB) public; the repo already contains FuXi and the FuXi-ENS ONNX-reverse-engineering + onnxruntime-parity method, so the port is a known recipe and adds *S2S*. Caveat: CC-BY-NC-ND-4.0 (check that a derivative re-implementation is acceptable; never commit the weights).
8. **TropiCycloneNet** (*Nat. Commun.* 2025) — PyTorch, public code/checkpoint/dataset; small; adds an observation-driven *TC track/intensity* model alongside WN-Cyclones.

Next tier: Generative SuperEnsemble (Zenodo weights 1.1 GB), Latent DA (checkpoints 3.9 GB, DA category), KIST-Ocean (6.6 M params, easiest trainable ocean model), DGMR (nowcasting, TF→PyTorch), FuXi-Weather (ONNX, NC-ND, DA part hard), WenHai (ONNX), IceNet, Ham 2019 ENSO CNN (tiny, retrain).
